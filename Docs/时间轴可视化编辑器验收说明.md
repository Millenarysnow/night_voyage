# 时间轴可视化编辑器验收说明

本文用于验收 NV Timeline 的首版可视化 JSON 编辑器。编辑器只负责静态编排数据，不会启动或修改游戏运行中的时间轴实例。

## 打开编辑器

1. 使用 Godot 4.8 编辑器打开项目，确认 `NV Timeline` 插件已启用。
2. 若刚刚重新构建了 GDExtension，先关闭并重新打开 Godot 编辑器；该扩展当前不可热重载。
3. 从“项目 > 工具 > NV Timeline”打开独立窗口。
4. 点击“打开”，选择 `res://addons/nv_timeline/examples/basic.timeline.json`。

打开后应看到唯一的“示例流程”时间轴、两条轨道、片段、输出与阻塞标记，以及左侧的全程输入列表。点击画布标尺左侧的时间轴名称后，右侧属性面板应显示可编辑的总时长；选中轨道、片段或列表项后，右侧显示对应用户属性，内部 ID 不显示。

## 画布编辑

1. 单击时间轴空白位置，将播放头移动到对应时间。标尺每 1.0 秒显示标签，最小吸附单位为 0.1 秒。
2. 选中一条轨道，点击“新增片段”。新片段应出现在播放头之后的第一个空闲区间；再次在同一时刻新增片段时，编辑器应自动放到该轨道的下一个空闲区间，片段之间不得重叠。轨道表头仍与画布行对齐。
3. 拖动片段中部可移动片段；拖动左右边缘可调整起点或长度。选中片段后可在右侧改名、设置起点/长度和颜色，点击“应用属性”提交。
4. 点击“输出标记”或“阻塞输入”，在播放头位置添加对应标签标记。拖动标记竖线可改变时间；右侧可以修改名称、类型、时间和标签。
5. 选中片段或标记后，使用右侧删除按钮移除它。该操作只删除所选对象。
6. 点击“新增输入”，在左侧列表选择全程输入，修改名称、标签或启用状态；使用列表下方的“删除”按钮移除所选输入。

## 时间范围边界

示例时间轴的有限时长是 40 个单位，即 4.0 秒。将播放头放到最右端 4.0 秒并新增片段，片段应被限制在有效区间 `[3.9, 4.0)`，对应 JSON 的 `start=39`、`duration=1`。超出有限时长的标记或片段属性会被文档校验拒绝，原数据保留。

## 撤销与文件往返

1. 新增或移动一个对象，点击“撤销”，确认最近一次成功编辑被还原；再点击“重做”，确认修改恢复。
2. 点击“另存为”，选择一个新文件路径，避免覆盖基础示例。
3. 关闭窗口后重新打开已保存文件，检查对象数量、时间、标签、颜色、轨道顺序和 ID 均保留。
4. 再次修改文档后观察窗口标题中的 `*`；保存成功后星号应消失。
5. 修改文档后尝试新建、打开其他文档或关闭窗口，确认出现未保存修改提示。取消后当前内容应继续保留。

## 数据边界

- 片段只负责可视化组织，不在进入、离开或完成时触发业务回调。
- 输出标记、阻塞输入和全程输入都只保存标签，不包含脚本路径、方法名、处理类或 AI 知识配置。
- 保存后的 JSON 应通过插件自身的严格字段、类型、ID 引用和时间范围校验。
- 滚动位置、缩放、播放头、当前选择、撤销历史和窗口状态不写入 JSON。
- 每个文件只能保存一条时间轴；需要多个独立时间轴时使用多个 `.timeline.json` 文件。
