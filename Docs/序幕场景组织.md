# 序幕场景组织

序幕的 `main.tscn` 只保留 `PrologueMain` 根节点。它负责加载 C++ 状态机、装配可编辑场景、连接信号和投影状态；桌面、窗口、登录页和动态控件的视觉结构不再在 C# 中创建。

## 场景层级

```text
main.tscn
└── PrologueMain (script/PrologueMain.cs)
    ├── PrologueDesktop (content/prologue/scenes/prologue_desktop.tscn)
    │   └── CRTViewport / ContentViewport
    │       └── DesktopContent (desktop_content.tscn)
    │           ├── Wallpaper / DesktopShade
    │           ├── DesktopIcons
    │           │   ├── chat / browser / board (desktop_app_icon.tscn)
    │           ├── WindowLayer
    │           ├── Toasts
    │           └── Taskbar (taskbar.tscn)
    ├── chat / browser / board (运行时加载的窗口场景)
    ├── ImageLightbox (image_lightbox.tscn)
    ├── LockScreen (lock_screen.tscn)
    └── NVPrologueState (C++ GDExtension 节点)
```

## 可编辑资源

| 资源 | 用途 |
| --- | --- |
| `content/prologue/scenes/prologue_desktop.tscn` | CRT 屏幕、背板和桌面内容的组合位置 |
| `content/prologue/scenes/desktop_content.tscn` | 壁纸、暗角、桌面图标列、窗口层、通知容器和任务栏 |
| `content/prologue/scenes/desktop_app_icon.tscn` | 单个桌面图标的控件结构、色块、阴影和标签布局 |
| `content/prologue/scenes/taskbar.tscn` | 夜航 OS 标识、任务栏按钮容器、用户名、托盘和时钟 |
| `content/prologue/scenes/window_chrome.tscn` | 所有应用共用的玻璃窗、标题栏、最小化/关闭按钮和 Body 插槽 |
| `content/prologue/scenes/chat_window.tscn` | 暗线窗口的位置、尺寸和窗口正文场景实例 |
| `content/prologue/scenes/browser_window.tscn` | 浏览器窗口的位置、尺寸和 CEF Host 插槽 |
| `content/prologue/scenes/board_window.tscn` | 白板窗口的位置、尺寸和任务区正文场景实例 |
| `content/prologue/scenes/lock_screen.tscn` | 登录壁纸、渐变、扫描线、登录卡和欢迎文字 |
| `content/prologue/scenes/chat_message.tscn` | 单条入站/出站消息的头像、气泡和换行布局 |
| `content/prologue/scenes/clue_card.tscn` | 白板线索卡结构和拖放句柄 |
| `content/prologue/scenes/task_drop_zone.tscn` | 白板任务投放区结构 |
| `content/prologue/scenes/free_drop_zone.tscn` | 白板自由区结构 |
| `content/prologue/scenes/toast.tscn` | 右下角通知结构和文字裁切 |
| `content/prologue/scenes/image_lightbox.tscn` | 图片灯箱、收录按钮和关闭按钮 |

图标实例的应用 ID使用节点名（`chat`、`browser`、`board`）；显示字形、标题和色块保存在 `desktop_content.tscn` 的节点元数据中。这样新增桌面图标时可以复制场景实例并修改场景数据，不需要改窗口控制器。

## 运行时职责

`PrologueMain.cs` 只做以下工作：

- 使用 `GD.Load<PackedScene>()` 加载上述资源并把窗口放入 `WindowLayer`。
- 连接场景节点已有的按钮、输入框、拖放区和 CEF Host。
- 用 `ChatMessageView`、`ClueCardView`、`TaskDropZoneView` 等模板实例化重复项目。
- 把 C++ `NVPrologueState` 的快照写入场景节点；剧情规则不在 UI 场景或 C# 中复制。

窗口位置、尺寸、标题栏样式、登录卡布局、任务区留白和 CRT 参数应优先在对应 `.tscn` 或插件资源中调整。C# 只在确实由状态或玩家操作决定的地方修改文本、可见性、纹理和窗口层级。
